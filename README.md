# Liga de Pádel Los Juncos

Aplicación web (Next.js + Supabase). Empieza por `docs/GUIA.md`.

- `supabase/schema.sql`: base de datos, seguridad y datos iniciales
- `app/`: páginas (inicio, clasificación, partidos, parejas, admin)
- `components/`, `hooks/`, `lib/`: interfaz y lógica
- `tests/`: pruebas de la lógica (`npm test`)
- `docs/FOTOS.md`: guía de fotos
